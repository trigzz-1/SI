SOCIAL INNOVATION PORTFOLIO - KLE Tech
======================================
Open index.html in any browser (no install needed).

HOW TO FILL IT IN
1. Open js/content.js in any text editor (Notepad, VS Code).
2. Type your text between the quotes. Leave "" to keep the yellow "To add" hint.
3. Photos: copy images into the assets/ folder and set src: "assets/name.jpg".
4. Save and refresh the browser.

PUBLISH ONLINE (free): drag this whole folder onto vercel.com or netlify.com/drop.

Tab order (fixed by the course): Home, Introduction, Social Innovators,
Phase 1 Observation, Phase 2 Problem Identification, Phase 3 Solution Discernment,
Phase 4 Pilot Testing & Feedback, Phase 5 Reflections, ARC Framework,
Takeaways from the Course, Exhibition.

INNOVATOR PHOTOS are in assets/ (kurien.jpg, bunker-roy.jpg, harish-hande.jpg, jadav-payeng.jpg). Replace a file with the same name to change a photo.
